# Shopper Guide

1. Open the Kurs menu and choose an item.
2. Review the base price and converted display price.
3. Connect Freighter when ready to pay.
4. Check the wallet network and selected account.
5. Select **Pay with Freighter**.
6. Confirm merchant, issued asset, amount, memo, and fee.
7. Approve the signature and save the resulting transaction link.

The converted catalog price is informative until a payment quote is created.
The wallet prompt is the final source of truth before signing.
