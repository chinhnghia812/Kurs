# Mainnet Runbook

1. Set Freighter to Stellar Mainnet.
2. Open the live Vercel application.
3. Connect the configured contract administrator account.
4. Use **Read USD/XLM** to simulate the current rate.
5. Enter the demo ratio and select **Publish demo rate**.
6. Review the contract ID, function, arguments, and fee in Freighter.
7. Sign and wait for the transaction hash.
8. Verify success in Stellar Expert.

Rebuild expired transactions. Never resubmit an old envelope with a stale
sequence number or time bound.
